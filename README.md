# Траты — учёт личных расходов (PWA)

Одностраничное приложение без бэкенда: HTML + CSS + JS в одном файле, данные в `localStorage`, работает офлайн и ставится на iPhone как приложение.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Всё приложение: разметка, стили, логика (≈2 700 строк с комментариями) |
| `manifest.json` | Название, иконки, режим `standalone` |
| `sw.js` | Service worker: кэш оболочки и Chart.js для работы без интернета |
| `icons/` | `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` |
| `inbox-worker/` | Необязательный сервер «Входящие» для автоматического ввода трат из Apple Pay и SMS (Cloudflare Worker) |

## Как установить на iPhone

Service worker и установка работают только по **HTTPS**, поэтому папку нужно выложить на любой статический хостинг (бесплатно):

- **Netlify Drop** — откройте app.netlify.com/drop и перетащите папку `traty`. Через несколько секунд получите адрес вида `https://….netlify.app`.
- **GitHub Pages** — загрузите файлы в корень репозитория → Settings → Pages → Deploy from branch → `main` / `(root)`.
- **Cloudflare Pages** — аналогично, «Upload assets».

Затем откройте адрес в Safari на iPhone. При первом открытии приложение само покажет подсказку:
«Поделиться» (в iOS 26 — через меню «•••») → «На экран „Домой“» → «Добавить».

> Safari и приложение на экране «Домой» хранят данные **раздельно**. Установите приложение сразу и вносите траты уже в нём, или перенесите данные через экспорт и импорт JSON.

Проверить на компьютере: в папке выполните `python3 -m http.server 8000` и откройте `http://localhost:8000` (на localhost service worker тоже работает).

## Данные и резервные копии

- Всё хранится только на устройстве (`localStorage`). Приложение запрашивает у браузера постоянное хранилище.
- **Экспорт JSON** — полная копия (покупки, категории, шаблоны, настройки). На iPhone открывается меню «Поделиться» → «Сохранить в Файлы».
- **Экспорт CSV** — для Excel / Numbers / Google Таблиц: разделитель `;`, десятичная запятая, UTF-8 с BOM.
- **Импорт** — JSON (добавить к текущим или заменить всё) и CSV. CSV понимает собственный формат и простые таблицы с колонками `Дата/date`, `Сумма/amount`, `Валюта/currency`, `Категория/category`, `Комментарий/comment`. Даты — `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`.
- Раз в неделю на главном экране появляется напоминание сделать экспорт JSON (если есть свои, не демо, покупки).

## Траты из Apple Pay и SMS (автоматический ввод)

iOS не даёт приложениям читать уведомления и SMS, поэтому траты передаёт приложение «Команды»:

```
Оплата Apple Pay / SMS банка → автоматизация в «Командах» → сервер «Входящие» → «Траты» при открытии
```

Сервер — маленький бесплатный Cloudflare Worker (`inbox-worker/worker.js`). Это просто очередь: траты хранятся там, пока приложение их не заберёт (не дольше 30 дней), доступ — по секретному ключу. Все покупки по-прежнему хранятся на телефоне.

В приложении: **Настройки → Траты из Apple Pay и SMS**. Там же пошаговая инструкция, кнопки «Создать ключ», «Проверить связь», «Тестовая трата» и «Скопировать ссылку для команды».

### 1. Сервер (один раз, удобнее с компьютера)

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатный тариф).
2. **Storage & Databases → KV → Create**, имя `traty-inbox`.
3. **Workers & Pages → Create → Worker**, имя `traty-inbox` → **Deploy** → **Edit code**: замените код содержимым `inbox-worker/worker.js` → **Deploy**.
4. Воркер → **Settings → Bindings → Add → KV namespace**: имя переменной `INBOX`, хранилище `traty-inbox`.
5. **Settings → Variables and Secrets → Add**: тип **Secret**, имя `TOKEN`, значение — ключ из приложения (кнопка «Создать ключ»).
6. Адрес воркера (`https://traty-inbox.<ваше-имя>.workers.dev`) впишите в приложении и нажмите «Проверить связь».

Вариант для командной строки: `inbox-worker/wrangler.toml` (команды — в комментарии файла).

### 2. Автоматизация для Apple Pay

«Команды» → «Автоматизация» → «+» → **«Транзакция»** → все карты, «Запускать сразу» → «Новая пустая команда» → действие **«Получить содержимое URL»**:

- URL — ссылка из кнопки «Скопировать ссылку для команды» (`https://…workers.dev/tx?key=<ключ>`);
- метод **POST**, текст запроса **JSON**, текстовые поля:
  - `amount` → «Входные данные команды» → свойство «Сумма»;
  - `merchant` → свойство «Продавец»;
  - `card` → свойство «Карта» (необязательно);
  - `source` → `wallet`.

### 3. SMS банка (необязательно)

Включите SMS о покупках в приложении банка. Затем «Автоматизация» → «+» → **«Сообщение»** (отправитель — банк, или «Сообщение содержит» `harcama`) → «Запускать сразу» → то же действие с POST и JSON: `text` → «Входные данные команды», `source` → `sms`.

Сумму, валюту и магазин приложение находит в тексте само (форматы `450,00 TL`, `₺1.234,50`, `$9.99`, `1 500 руб.` и т. п.). SMS с кодами подтверждения пропускаются.

### Как это работает в приложении

- Новые траты забираются при открытии приложения и при возвращении в него.
- **Входящие**: трата с подсказанной категорией → «Добавить» (или «Изменить» — откроется обычная форма).
- Подтверждённая категория запоминается для магазина (в том числе для других филиалов сети: `MIGROS 4521 KADIKOY` → `MIGROS 999 BESIKTAS`). Следующие траты в знакомых магазинах добавляются сразу — это можно выключить.
- Одна и та же покупка из Apple Pay и SMS помечается как возможный дубль и сама не добавляется.
- Список запомненных магазинов: **Настройки → Магазины и категории**.

## Курсы валют

1. **Frankfurter** (`api.frankfurter.dev/v2`) — официальные курсы центробанков, история по датам, один запрос на все валюты.
2. **currency-api** (jsDelivr, запасной адрес на Cloudflare Pages) — если Frankfurter недоступен.
3. **ExchangeRate-API** (`open.er-api.com`) — только текущий курс, для последних 7 дней.

Курсы кэшируются в `localStorage`: прошлые даты — навсегда, сегодняшний — на 6 часов.
Без интернета подставляется ближайший известный курс с пометкой «приблизительно» — он сам уточнится при подключении. Если курса нет совсем, его вводят вручную (так же, как курс обменника).

У каждой покупки хранятся: исходная сумма, валюта, применённый курс, источник курса (`auto` / `manual`), источник и дата авто-курса, сумма в основной валюте.

## Обновление приложения

Изменили файлы на хостинге → увеличьте `VERSION` в `sw.js` (например, `traty-v1.0.1`). У пользователей появится уведомление «Доступна новая версия · Обновить».

## Настройки по умолчанию

Основная валюта — TRY, дополнительные — USD, EUR, RUB. Всё меняется в «Настройках»; при смене основной валюты покупки и бюджеты пересчитываются по курсам на даты покупок (ручные курсы сохраняются через кросс-курс).
